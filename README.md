# Calculadora de Mercado

Aplicativo mobile feito com Expo e React Native para registrar compras, acompanhar itens e valores e definir metas de gastos.

## Desenvolvimento

Instale as dependências com `npm install` e inicie o Expo com `npx expo start`.

As telas ficam em `src/app/`, os estilos compartilhados em `src/theme/styles.ts` e o armazenamento local em `src/services/storage.ts`.
